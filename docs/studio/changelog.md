# Studio changelog

Short, user-facing notes for the Studio Changelog dialog. Keep this file free
of file paths, infrastructure details, issue numbers, and deployment commands.
Newest first.

## 2026-10-23 — Studio notes are now concise

The studio changelog now shows short, user-facing updates instead of technical release notes.

## 2026-10-23 — A changelog in the studio

The studio header now has a Changelog button with recent studio and radio improvements.

## 2026-10-23 — Background playback stays paused

Switching to another app now keeps Nakout paused in the background instead of interrupting the other app's audio.

## 2026-10-23 — Overnight shows stay highlighted

The current show stays highlighted after midnight until the next scheduled show begins.

## 2026-10-22 — The studio queue follows the live play order

The queue now shows the actual play order, and shuffle or reorder changes that order.

## 2026-10-22 — Fewer repeated tracks in automatic runs

Automatic genre runs now remember what has aired and avoid heavy repeats.

## 2026-10-19 — Round album art on the vinyl label

The record label now shows round album art without square edges.

## 2026-10-19 — Playback survives screen lock

Phones keep playing through track changes when the screen locks or the page goes inactive.

## 2026-10-17 — Consistent volume across tracks

Tracks are normalized to a consistent volume.

## 2026-10-17 — No immediate repeat when a genre queue wraps

A genre queue no longer starts over with the same track when it wraps.
